# Projek Latihan GitHub 2

Project ini merupakan latihan penggunaan Git dan GitHub dengan menggunakan framework CodeIgniter 4.

## Deskripsi
Pada project ini dibuat sebuah aplikasi kalkulator sederhana menggunakan HTML, CSS, dan JavaScript yang kemudian diintegrasikan ke dalam framework CodeIgniter 4.

## Teknologi yang Digunakan
- CodeIgniter 4
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Cara Menjalankan Project
1. Clone repository ini
2. Masuk ke folder project
3. Jalankan perintah berikut di terminal

php spark serve

4. Buka browser dan akses

http://localhost:8080/calculator
